# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Cirnouo/opssh/security/advisories/new). If the private form is unavailable, [open an issue](https://github.com/Cirnouo/opssh/issues/new) asking maintainers for a secure contact method. Keep vulnerability details and reproduction material private until a secure channel is available.

Include the affected opssh version or commit, Windows version, impact, prerequisites and the smallest safe reproduction. Use generated keys and test data. Remove private keys, credentials, account and vault identifiers, personal paths, SSH destinations, complete configuration, raw provider errors and process dumps. Reproduce only against accounts, processes and data you are authorized to use.

Coordinate disclosure with maintainers. For setup questions and ordinary bugs, use the [support guide](SUPPORT.md).
