# Windows 离线性能

在 Windows 11 26H2 x64（内部版本 26300）上，以已发布构建配置的自包含 WinUI 3 托盘和带 `opssh_fixture` 构建标签的 Go 核心采样。每轮启动新的托盘和核心进程，共三轮，保留操作系统文件缓存。核心使用内存生成的 Ed25519 测试密钥和 mock 存储，取钥发生在首次批准签名时。采样使用的候选构建早于锁定和解锁命令的最终排序修复。

| 采样时的状态 | Go 工作集 / 私有提交量（MiB） | WinUI 3 工作集 / 私有提交量（MiB） |
| --- | ---: | ---: |
| 密钥未加载，设置窗口关闭 | 16.94 / 50.18 | 145.91 / 100.88 |
| 密钥未加载，设置窗口打开 | 16.94 / 50.18 | 148.72 / 102.18 |
| 密钥已加载，设置窗口关闭 | 17.60 / 51.23 | 165.31 / 108.96 |
| 密钥已加载，设置窗口打开 | 17.71 / 51.38 | 165.52 / 109.09 |

每次窗口状态变化或首次签名结束后等待 900 ms，分别记录两个进程的 `WorkingSet64` 和 `PrivateMemorySize64`，表中是各项中位数。关闭设置窗口会隐藏窗口并保留托盘进程。后两组是在打开过审批界面之后采样，包含 WinUI 界面初始化的开销。

| 端到端计时 | 中位数（ms） | 三轮范围（ms） |
| --- | ---: | ---: |
| 从启动托盘到系统 `ssh-add -L` 返回公钥 | 2,089.5 | 2,060.4–2,117.7 |
| 首次签名，含自动化选择宿主和点击批准 | 447.6 | 344.9–471.8 |
| 从自动化点击批准到首次签名完成 | 37.0 | 32.0–51.8 |
| 已批准宿主的新子进程签名，批准和私钥均命中缓存 | 86.6 | 85.5–98.3 |

签名使用系统 `ssh-keygen -Y sign` 和临时本地管道，耗时包含 OpenSSH 客户端进程启动。后两轮同时检查了缓存命中时托盘未打开审批窗口。三轮均观察到托盘异常退出后测试核心退出。这些样本没有测量实际 1Password 解锁、授权提示或取钥的时间和内存开销。
