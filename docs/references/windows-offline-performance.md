# Windows 离线性能

## 自动索引与设置窗口改版

在同一台 Windows 11 x64 虚拟机 `vm001` 的交互会话，对初版 `c9a168f` 和改版候选树 `6ca7ff0` 的自包含 Release 托盘各采样三轮。每轮启动新的托盘和 Go 测试核心，使用生成的 Ed25519 密钥和本地 OpenSSH 命名管道。每个状态在切换后等待 900 ms，再记录工作集和私有提交量。保留操作系统文件缓存，未清空进程工作集。

每格为工作集 / 私有提交量的中位数，单位 MiB。

| 状态 | 初版 Go 核心 | 改版 Go 核心 | 初版 WinUI 3 托盘 | 改版 WinUI 3 托盘 |
| --- | ---: | ---: | ---: | ---: |
| 密钥未加载，从未打开设置 | 52.16 / 46.72 | 52.17 / 46.61 | 117.21 / 36.39 | 69.09 / 20.86 |
| 密钥未加载，设置打开 | 52.28 / 46.90 | 52.29 / 46.84 | 125.30 / 37.21 | 133.53 / 39.88 |
| 密钥未加载，打开设置后关闭 | 52.28 / 46.90 | 52.29 / 46.84 | 121.57 / 37.20 | 135.28 / 39.79 |
| 密钥已加载，设置关闭 | 52.57 / 47.32 | 52.66 / 47.42 | 133.42 / 42.08 | 139.34 / 43.14 |
| 密钥已加载，设置打开 | 52.57 / 47.32 | 52.66 / 47.42 | 138.12 / 42.35 | 151.36 / 47.73 |

从未打开设置时，改版托盘少用 48.12 MiB 工作集和 15.53 MiB 私有提交量。打开过设置再关闭后，改版工作集高 13.71 MiB，私有提交量高 2.59 MiB。三轮均观察到新版启动时没有设置窗口，关闭时窗口句柄销毁，托盘和核心继续运行。这组数据区分了延迟创建窗口的收益与使用过 WinUI 界面后的常驻成本。

| 端到端计时 | 初版中位数（ms） | 改版中位数（ms） |
| --- | ---: | ---: |
| 启动到系统 `ssh-add -L` 返回公钥 | 9,944.0 | 6,670.8 |
| 首次签名，含自动化选择宿主和点击批准 | 512.4 | 543.2 |
| 从自动化点击批准到首次签名完成 | 66.8 | 71.1 |
| 新子进程命中批准与私钥缓存 | 58.7 | 84.6 |

计时包含 OpenSSH 客户端启动。改版的缓存命中用时在 60.9–164.3 ms 间波动，三轮均未打开新的审批窗口。使用的密钥由离线 fixture 提供，实际 1Password 的授权、发现和取钥开销需单独测量。

## 初版物理机采样

在 Windows 11 26H2 x64（内部版本 26300）上，以已发布构建配置的自包含 WinUI 3 托盘和带 `opssh_fixture` 构建标签的 Go 核心采样。每轮启动新的托盘和核心进程，共三轮，保留操作系统文件缓存。核心使用内存生成的 Ed25519 测试密钥和 mock 存储，取钥发生在首次批准签名时。采样使用的候选构建早于锁定和解锁命令的最终排序修复。

| 采样时的状态 | Go 工作集 / 私有提交量（MiB） | WinUI 3 工作集 / 私有提交量（MiB） |
| --- | ---: | ---: |
| 密钥未加载，设置窗口关闭 | 16.94 / 50.18 | 145.91 / 100.88 |
| 密钥未加载，设置窗口打开 | 16.94 / 50.18 | 148.72 / 102.18 |
| 密钥已加载，设置窗口关闭 | 17.60 / 51.23 | 165.31 / 108.96 |
| 密钥已加载，设置窗口打开 | 17.71 / 51.38 | 165.52 / 109.09 |

每次窗口状态变化或首次签名结束后等待 900 ms，分别记录两个进程的 `WorkingSet64` 和 `PrivateMemorySize64`，表中是各项中位数。关闭设置窗口会隐藏窗口并保留托盘进程。后两组是在打开过审批界面之后采样，包含 WinUI 界面初始化的开销。

| 端到端计时 | 中位数（ms） | 三轮范围（ms） |
| --- | ---: | ---: |
| 从启动托盘到系统 `ssh-add -L` 返回公钥 | 2,089.5 | 2,060.4–2,117.7 |
| 首次签名，含自动化选择宿主和点击批准 | 447.6 | 344.9–471.8 |
| 从自动化点击批准到首次签名完成 | 37.0 | 32.0–51.8 |
| 已批准宿主的新子进程签名，批准和私钥均命中缓存 | 86.6 | 85.5–98.3 |

签名使用系统 `ssh-keygen -Y sign` 和临时本地管道，耗时包含 OpenSSH 客户端进程启动。后两轮同时检查了缓存命中时托盘未打开审批窗口。三轮均观察到托盘异常退出后测试核心退出。这些样本没有测量实际 1Password 解锁、授权提示或取钥的时间和内存开销。
