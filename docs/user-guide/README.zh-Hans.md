# opssh 使用指南

[English](README.md) · **简体中文** · [项目概览](../../README.zh-Hans.md)

通过 opssh，Windows x64 系统 OpenSSH 客户端可以使用 1Password 桌面应用中的 SSH 密钥签名。先[安装](#install)并[连接 1Password](#connect)，再[选择 SSH 代理](#select-agent)，并[批准首次签名请求](#approve-signing)。

<a name="install"></a>

## 安装并启动 opssh

准备装有系统 OpenSSH 客户端的 Windows x64、PowerShell，以及已登录且存有 SSH Key 条目的 1Password 桌面应用。首次连接时，请使用已经接受该条目公钥的 SSH 主机。

正式发行版发布后，请下载 Windows x64 MSI。它会为当前用户安装到 `%LOCALAPPDATA%\Programs\opssh`。安装器和 opssh 二进制文件均未签名。[GitHub 发行版](https://github.com/Cirnouo/opssh/releases)

首次交互安装的完成页默认勾选 **登录 Windows 时启动 opssh** 和 **将 opssh 设为默认 SSH 代理**。取消勾选自启会禁用默认代理选项。选择 **Skip** 可跳过这两项设置。如果 Windows 询问是否允许更改 OpenSSH 服务，请批准以完成默认代理切换。升级、修复或静默安装后可在 opssh 中调整设置。可从开始菜单打开 **opssh**。

卸载前请关闭 **登录 Windows 时启动**，如有提示请确认 **恢复 OpenSSH**。如果 opssh 正在运行，请在安装、修复、升级或卸载前，右键点击托盘图标并选择 **退出 opssh**。已安装的程序由 Windows **已安装的应用** 管理。卸载会移除程序文件和开始菜单快捷方式，保留 `%LOCALAPPDATA%\opssh` 中的设置和公钥索引。

如需从源代码构建，请参阅[开发与贡献指南](../../CONTRIBUTING.md)。

<a name="connect"></a>

## 连接 1Password 并查看密钥

1. 在 1Password 桌面应用中登录，安装官方 1Password CLI。启用 Windows Hello，并在 **设置 → 开发者** 中开启 CLI 和 SDK 集成。[CLI 桌面集成](https://www.1password.dev/cli/app-integration) · [桌面 SDK 集成](https://www.1password.dev/sdks/desktop-app-integrations)
2. 从托盘打开 opssh，选择 **连接 1Password**。列表默认选中第一个账户，显示邮箱，有用户名时同时显示。选择 **在 1Password 中继续**，按提示完成授权。
3. 在 **1Password** 页选择允许发现的保险库。进入 **SSH 密钥**，点击 **发现 SSH 密钥**。窗口较窄时，用标题栏的导航按钮切换页面。

opssh 保存已选账户和公钥索引。**1Password** 页显示上次请求的结果和本地时间，下次请求时 1Password 仍可能要求授权。切换账户或选择 **移除账户** 会清除原账户的保险库范围、公钥索引、私钥缓存、授权和活动。

<a name="select-agent"></a>

## 切换或恢复 SSH 代理

opssh 已作为默认 SSH 代理时，直接使用 Windows OpenSSH。若要为单个会话指定代理，请按以下步骤操作。

1. 在要使用 opssh 的 PowerShell 窗口中，先保存当前的代理设置。

   ```powershell
   $previousSshAuthSock = $env:SSH_AUTH_SOCK
   ```

2. 在 opssh 中打开 **设置 → SSH 集成 → 当前 PowerShell 会话**。点击 **复制命令**，粘贴到该窗口并执行。
3. 用系统 OpenSSH 运行 `ssh-add -L`，确认列表中有预期的公钥。如果 SSH 使用了其他代理，请检查 SSH 配置中的 `IdentityAgent`。该设置可能覆盖 `SSH_AUTH_SOCK`。

此命令只影响当前 PowerShell 进程及其启动的进程。要恢复之前的代理设置，关闭该窗口，或在同一窗口中执行以下命令。

```powershell
$env:SSH_AUTH_SOCK = $previousSshAuthSock
```

开启 **登录 Windows 时启动** 后，可在 **设置 → SSH 集成** 中将 opssh 设为系统默认 SSH 代理。默认管道生效后，PowerShell 卡片会隐藏。对话框会显示正在执行的步骤。停止和禁用自动运行的 Windows OpenSSH 代理时，Windows 可能会要求管理员批准。退出 opssh 会释放管道，默认代理选择仍然保留。关闭默认代理开关后，选择 **恢复 OpenSSH** 可恢复 Windows 服务。关闭开机自启时，opssh 也会在需要时先询问是否恢复 OpenSSH。

在 **设置 → 启动** 中开启 **等待 1Password 启动**，1Password 就绪时会收到 Windows 通知。点击通知、选择账户，然后选择 **在 1Password 中继续** 来请求授权。选择当前账户会保留其保险库范围、密钥、授权和活动。

<a name="approve-signing"></a>

## 批准 SSH 签名

用平时的 `ssh` 命令连接接受其中一个公钥的主机。在 opssh 的 Windows 通知中核对应用、PID 和密钥指纹。SSH 代理请求不包含经过验证的远程目标。

| 选项 | 批准范围 |
| --- | --- |
| **授权此应用** | 允许所示应用及其经验证的后代复用该密钥。如果未找到符合条件的窗口所属进程，授权仅覆盖经过验证的请求进程实例。 |
| **仅授权请求** | 仅批准当前签名。 |
| **拒绝** | 拒绝当前签名。 |

批准缓存设为「不缓存」时，只提供本次授权和拒绝。如需撤销应用授权，请在 **SSH 密钥** 中展开对应的密钥。Windows 禁用或拒绝发送通知时，opssh 会拒绝请求，并在活动中记录结果。关闭通知后，请求会在截止时过期。

如果已批准的请求需要私钥，opssh 会从 1Password 读取。如有提示，请在 1Password 窗口中单独授权。关闭设置窗口后，托盘应用和代理会继续运行。选择 **退出 opssh** 会结束两者。

<a name="key-scope"></a>

## 选择和刷新密钥

在 **1Password** 页允许或排除保险库，更改立即生效。排除后会撤下对应的公钥，清除其私钥缓存和进程授权。新允许的保险库在下次手动发现时纳入。已有条目规则保留到你显式更改所属保险库的选项。账户级访问权限由 1Password 管理。

新增、轮换、归档或删除密钥后，再次点击 **发现 SSH 密钥**。如果范围过大，请缩小至最多 64 把密钥。

<a name="caches-and-lock"></a>

## 管理密钥缓存和批准

在 **设置 → 缓存策略** 中展开相应卡片，独立设置私钥和进程授权的保留时间。可选 **不缓存**、**固定时长**、**空闲超时** 或 **直到 opssh 退出**。默认固定时长为私钥 5 分钟和授权 10 分钟。空闲时间在成功签名后重新计算。进程结束时，该进程的授权到期。

在 **SSH 密钥** 页可逐把或批量预加载、清除私钥。预加载失败时，在对应密钥旁查看原因，解决后可重试。批量预加载会保留已成功加载的私钥。排查失败原因时，可先启用 **DEBUG** 日志再重试。展开公钥可查看进程名、PID 和本地到期时间。可撤销单条授权、该密钥全部授权或所有授权。锁定 1Password 会结束新的读取权限，已加载的私钥遵循 opssh 的缓存策略。

## 查看活动

**活动** 页显示当前 opssh 会话的近期签名结果。可按应用、密钥、结果和本地日期多选，同组满足任意一项即可，不同组需同时满足。长命令上使用 Shift＋滚轮可横向滚动，到边界后继续滚动会移动表格。命令可能包含敏感值，仅在本机会话的活动页显示。点击 **清除活动** 可丢弃会话历史。

<a name="diagnostic-logs"></a>

## 查看诊断日志

在 **设置 → 日志** 中启用本地诊断日志。日志默认关闭，默认级别为 **INFO**。签名和预加载的完成记录可显示请求执行到哪些步骤，以及每一步的耗时和结果。签名请求超时时，可检查最后一步是等待授权还是等待私钥。日志不记录私钥、账户信息、进程信息或 SSH 请求内容。选择 **打开目录** 可在 Windows 资源管理器中直接打开日志目录。目录中最多有一个当前日志和两个轮转文件。每个文件最多 1 MiB。选择 **清理日志** 并确认后，即可删除现有日志文件。关闭日志后将停止写入新记录。

<a name="appearance-and-updates"></a>

## 设置外观和检查更新

在 **设置 → 偏好** 中选择英语、简体中文或 **跟随系统**。默认在托盘启动时读取 Windows 显示语言，其他语言使用英语。主题可选浅色、深色或跟随系统。重启后会保留这些偏好。切换语言会重新打开窗口。

在 **关于** 中选择 **检查更新**，可以查找更新的正式发行版。**自动检查更新** 默认开启，每次启动托盘时检查一次，发现新版会显示 Windows 通知。选择 **打开 GitHub 发行页** 查看发行版，再按[安装步骤](#install)升级。

<a name="troubleshooting"></a>

## 故障处理

| 现象 | 处理方法 |
| --- | --- |
| 托盘已启动，但核心不可用 | 如果托盘菜单中的 **重启核心** 可用，请选择它。如果仍无法启动核心，请修复 MSI 安装。 |
| 连接、刷新或加载密钥时被拒绝或超时 | 确认账户，解锁 1Password 桌面应用，检查 SDK 集成，并完成窗口中的提示。然后重试刚才的操作。如果读取仍然超时，请退出并重新打开 opssh 来重启核心。 |
| 找不到预期密钥，或轮换后无法使用 | 确认它是仍可使用的 SSH Key 条目，检查保险库选项后重新发现。opssh 支持 Ed25519，以及使用 SHA-2 签名的 2048–4096 位 RSA 密钥。 |
| SSH 使用了其他代理或无法连接 opssh | 确认托盘正在运行，再在遇到问题的 PowerShell 会话中重新执行显示的命令。检查该主机的 SSH 配置是否设置了 `IdentityAgent`。 |
| SSH 能列出密钥，但无法签名 | 重试 SSH，并完成签名批准及 1Password 的单独授权提示。 |
| 签名后仍无法登录 | 核对用户名，并确认主机已授权对应的公钥。 |

求助时，请提供 opssh 版本、Windows 版本、遇到问题的步骤和已脱敏的反馈。请勿公开私钥、凭据、账户或保险库 ID、个人路径、SSH 目标、完整配置文件或原始提供方错误。[使用支持](../../SUPPORT.md) · [私下报告漏洞](../../SECURITY.md)
