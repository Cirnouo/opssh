# opssh 使用指南

[English](README.md) · **简体中文** · [项目概览](../../README.zh-Hans.md)

通过 opssh，Windows x64 系统 OpenSSH 客户端可以使用 1Password 桌面应用中的 SSH 密钥签名。先[安装](#install)并[连接 1Password](#connect)，再[在 PowerShell 中选择代理](#select-agent)，并[批准首次签名请求](#approve-signing)。

<a name="install"></a>

## 安装并启动 opssh

准备装有系统 OpenSSH 客户端的 Windows x64、PowerShell，以及已登录且存有 SSH Key 条目的 1Password 桌面应用。首次连接时，请使用已经接受该条目公钥的 SSH 主机。

正式发行版发布后，请选择适合你的 Windows x64 安装包。安装器和 opssh 二进制文件均未签名。[GitHub 发行版](https://github.com/Cirnouo/opssh/releases)

| 下载项 | 安装和启动 |
| --- | --- |
| MSI 或离线 EXE 安装器 | 运行任一安装器，为当前用户安装到 `%LOCALAPPDATA%\Programs\opssh`。安装后从开始菜单打开 **opssh**。 |
| 便携 ZIP | 将压缩包解压到一个文件夹，并运行其中的 `opssh-tray.exe`。将解压后的文件保留在同一目录中。 |

如果 opssh 正在运行，请在安装、修复、升级或卸载前，右键点击托盘图标并选择 **退出 opssh**。已安装的程序由 Windows **已安装的应用** 管理。卸载会移除程序文件和开始菜单快捷方式，保留 `%LOCALAPPDATA%\opssh` 中的设置和公钥索引。

如需从源代码构建，请参阅[开发与贡献指南](../../CONTRIBUTING.md)。

<a name="connect"></a>

## 连接 1Password 并查看密钥

1. 在 1Password 桌面应用中登录账户。打开 1Password 的 **设置 → 开发者**，开启 **与 1Password SDK 集成**。[1Password 桌面应用 SDK 集成](https://www.1password.dev/sdks/desktop-app-integrations)
2. 右键点击 opssh 托盘图标，选择 **打开 opssh**。进入 **1Password 和密钥**，输入 1Password 侧边栏显示的账户名称或 ID。
3. 选择 **连接**，在 1Password 窗口中完成所需的验证或授权。在 **可用的 SSH 密钥** 中检查是否有预期的密钥。

新配置默认索引账户可访问的所有保险库中的可用 SSH Key 条目。如果希望从空索引开始，请在连接前将 **发现范围** 的默认规则设为 **全部排除**，并选择 **应用范围**。连接后[只纳入需要的密钥](#key-scope)。opssh 会保存账户和公钥列表，并在启动时恢复。下次读取 1Password 时可能需要重新授权。

<a name="select-agent"></a>

## 切换或恢复 SSH 代理

1. 在要使用 opssh 的 PowerShell 窗口中，先保存当前的代理设置。

   ```powershell
   $previousSshAuthSock = $env:SSH_AUTH_SOCK
   ```

2. 在 opssh 中打开 **概览 → SSH 客户端设置 → PowerShell → 显示命令**。将显示的命令复制到该窗口并执行。
3. 用系统 OpenSSH 运行 `ssh-add -L`，确认列表中有预期的公钥。如果 SSH 使用了其他代理，请检查 SSH 配置中的 `IdentityAgent`。该设置可能覆盖 `SSH_AUTH_SOCK`。

此命令只影响当前 PowerShell 进程及其启动的进程。要恢复之前的代理设置，关闭该窗口，或在同一窗口中执行以下命令。

```powershell
$env:SSH_AUTH_SOCK = $previousSshAuthSock
```

<a name="approve-signing"></a>

## 批准 SSH 签名

用平时的 `ssh` 命令连接接受其中一个公钥的主机。opssh 提示批准时，核对密钥指纹和发起请求的进程。如需批准上级进程，请先通过进程链确认其身份。SSH 代理请求不包含经过验证的远程目标。

| 选项 | 批准范围 |
| --- | --- |
| **仅允许一次** | 仅批准当前签名。 |
| **允许此客户端** | 同一客户端进程后续使用同一密钥时，可按批准缓存策略复用。 |
| **允许所选上级进程** | 选中且仍在运行的进程及其经验证的后代使用同一密钥时，可按批准缓存策略复用。 |
| **拒绝** | 拒绝当前签名。 |

如果已批准的请求需要私钥，opssh 会从 1Password 读取。如有提示，请在 1Password 窗口中单独授权。关闭设置窗口后，托盘应用和代理会继续运行。选择 **退出 opssh** 会结束两者。

<a name="key-scope"></a>

## 选择和刷新密钥

在 **1Password 和密钥 → 发现范围** 中选择账户默认规则，也可为单个保险库或 SSH Key 条目设置覆盖规则。条目规则优先于所在保险库的规则。选择 **继承** 会采用最近的上一级规则。选择 **应用范围** 保存。旧版手动选择密钥的配置会保留原有范围。范围决定 opssh 索引和使用哪些密钥，整个账户的读取权限由 1Password 单独管理。

在 1Password 中新增、轮换、归档或删除密钥后，进入 **1Password 和密钥 → 公钥索引 → 刷新索引**。确认列表已更新，再重试 SSH。如果提示范围过大，请缩小到最多 64 个密钥。如果设置提示超出保险库或条目发现上限，请按提示调整后重新刷新。

<a name="caches-and-lock"></a>

## 管理密钥缓存和批准

在 **批准和缓存 → 更改缓存策略** 中分别配置私钥缓存和批准缓存。默认情况下，加载的私钥保留固定 5 分钟，进程批准保留固定 10 分钟。每项都可选择 **关闭**、**固定时长**、**空闲超时** 或 **直到锁定**，然后选择 **应用缓存设置**。固定时长从密钥加载或请求获批时开始计算。空闲计时在成功签名后重新计算。

- 要提前加载密钥，请在 **1Password 和密钥 → 可用的 SSH 密钥** 中选中密钥，再选择 **预加载所选密钥**。
- 要清除已加载的私钥，请选择 **清除已加载的私钥**。进程批准仍可复用。
- 要求重新批准时，可选择 **撤销所有批准**，也可先在 **1Password 和密钥** 中选中密钥，再在 **批准和缓存** 中选择 **撤销所选密钥的批准**。
- 要清除两者并暂停签名，请选择 **概览 → 代理锁定 → 锁定**。仍可列出公钥。再次签名前请选择 **解锁**。

锁定 1Password 会结束它授予的读取权限。opssh 已加载的私钥仍遵循本地缓存策略。需要同时清除已加载的私钥和批准时，也请锁定 opssh。

<a name="appearance-and-updates"></a>

## 设置外观和检查更新

在 **外观** 中选择英语、简体中文或 **跟随系统**。默认在托盘启动时读取 Windows 显示语言，其他语言使用英语。主题可选浅色、深色或跟随系统。重启后会保留这些偏好。切换语言会重新打开设置窗口，请先应用尚未保存的更改。

在 **关于** 中选择 **检查更新**，可以查找更新的正式发行版。**自动检查更新** 默认开启，每次启动托盘时检查一次，发现新版会显示 Windows 通知。选择 **打开 GitHub 发行页** 查看发行版，再按[安装步骤](#install)升级。

<a name="troubleshooting"></a>

## 故障处理

| 现象 | 处理方法 |
| --- | --- |
| 托盘已启动，但核心不可用 | 如果托盘菜单中的 **重启核心** 可用，请选择它。便携版请确认已完整解压 ZIP。 |
| 连接、刷新或加载密钥时被拒绝或超时 | 确认账户，解锁 1Password 桌面应用，检查 SDK 集成，并完成窗口中的提示。然后重试刚才的操作。如果读取仍然超时，请退出并重新打开 opssh 来重启核心。 |
| 找不到预期密钥，或轮换后无法使用 | 确认它是仍可使用的 SSH Key 条目，检查保险库和条目范围后刷新。opssh 支持 Ed25519，以及使用 SHA-2 签名的 2048–4096 位 RSA 密钥。 |
| SSH 使用了其他代理或无法连接 opssh | 确认托盘正在运行，再在遇到问题的 PowerShell 会话中重新执行显示的命令。检查该主机的 SSH 配置是否设置了 `IdentityAgent`。 |
| SSH 能列出密钥，但无法签名 | 检查 opssh 是否已锁定，再重试 SSH，并完成签名批准及 1Password 的单独授权提示。 |
| 签名后仍无法登录 | 核对用户名，并确认主机已授权对应的公钥。 |

求助时，请提供 opssh 版本、Windows 版本、遇到问题的步骤和已脱敏的反馈。请勿公开私钥、凭据、账户或保险库 ID、个人路径、SSH 目标、完整配置文件或原始提供方错误。[使用支持](../../SUPPORT.md) · [私下报告漏洞](../../SECURITY.md)
