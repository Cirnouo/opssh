# Changelog

## [Unreleased]

### Added

- SSH signing for the built-in Windows x64 OpenSSH client, with private keys fetched on demand from 1Password Desktop.
- A tray app to manage 1Password key scope and public key discovery, review signing requests, and approve a request, a process, or a host process and its descendants.
- English and Simplified Chinese tray text, light and dark themes, and stable release update checks.
- A per-user Windows x64 MSI with completion-page choices for login startup and the default SSH agent.
